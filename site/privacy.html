The tool

peepwho runs on your machine. The summary below comes from the full text in docs/PRIVACY.md.

  • The index lives at ~/.peepwho/index.json on your machine, readable only by you, and is never uploaded.
  • The index holds each person's name, email, title, team, and linked identities, topic weights, channel names with member lists, and a stemmed term index. Message bodies are not kept.
  • With no AI model configured, index, ask, and serve make no network requests at all.
  • The index can be encrypted at rest with AES-256-GCM. Set a key or passphrase and peepwho encrypts on every write.
  • The optional archive, enabled with --archive, keeps message text from Slack conversations on your disk. It refuses to run without an encryption key.
  • peepwho forget removes one person from everything peepwho stores.
  • peepwho wipe deletes every file peepwho writes under the data directory and every credential it saved in the OS keychain.
